# Android SDK ЮKassa → Kivy → сервер

Используется официальный SDK 8.6.0 из репозитория ЮMoney. Java-мост передаёт
одноразовый токен, тип метода и идентификатор локального запроса. Данных карты
в Python нет. Для первого запуска выбран только BANK_CARD. Mock-режим SDK
не включён: тестовые платежи должны проходить в настоящем тестовом магазине.

## Настройки клиента

`billing_config.json` содержит только публичную конфигурацию:
- адрес HTTPS API;
- shop_id настоящего магазина 1525689;
- sdk_key — ключ **мобильного SDK**, не секретный ключ API;
- public_key — закреплённый открытый RSA-ключ нашего сервера;
- test_mode=false.

Боевой SDK-ключ и открытый ключ сервера настроены. Секретный API-ключ
хранится только на хостинге. В интерфейсе предлагается покупка за 250 ₽ навсегда
или временный доступ за рекламу. Новые платные подписки больше не предлагаются;
восстановление и отмена автопродления существующих подписок сохранены.

Секретного ключа магазина и пароля БД в APK нет. Публичный ключ сервера был
получен разработчиком по HTTPS и закреплён в исходниках. Ответ entitlement
никогда не заменяет этот ключ при проверке лицензии.

Личный код, незавершённый заказ и подписанная лицензия сохраняются в закрытой
папке приложения `billing/test-1528155/access.json`, отдельно от БД кампании.
Для настоящего магазина используется другая папка `live-SHOP_ID`: тестовые
аккаунты и лицензии не переносятся в реальные покупки. Код можно
скопировать из окна покупок. Нельзя сохранять его в URL, логах или Git.
Сохранения кампании не удаляются. Бесплатно доступны Эльфы, Вампиры и Адепты.
Север, Элины, Зазеркалье, тактические бои и дополнительные механики требуют
действующего полного доступа.

## Реклама с вознаграждением

`com.yandex.android:mobileads:8.6.0`, блок `R-M-20420203-1`.
Java-мост `com.lerdonlegends.ads.RewardedBridge` запускает SDK только по
запросу игрока. Автоматическая инициализация SDK отключена в manifest-фрагменте.
Награда выдаётся исключительно по `onRewarded`: закрытие, ошибка и показ
объявления сами по себе не открывают контент. Подтверждённые события сохраняются
на Android до подтверждения записи Python, повторная доставка не даёт второй награды.

Один просмотр добавляет 900 секунд. `rewarded_time.py` сохраняет остаток в
закрытой папке приложения `rewarded/time.json`, отдельно от базы кампании.
Считается активное игровое время по монотонным часам; меню, окно выбора доступа,
фон, реклама и выход не расходуют минуты. Купленный доступ не расходует запас минут.
При истечении времени текущий бой/обработка хода завершается перед уведомлением.
Платная кампания ждёт продления или позволяет сохранить и выйти; бесплатная
кампания может продолжаться с бесплатными возможностями. Новая реклама не
запускается без нажатия игрока.

Для проверки SDK на устройстве используйте демоблок `demo-rewarded-yandex`
в отдельной тестовой сборке вместо рабочего ID. Проверьте полный просмотр,
раннее закрытие, отсутствие сети, повторный просмотр, сворачивание и перезапуск.
Не проверяйте выдачу награды автоматическими просмотрами рабочего блока.
Реальный показ рабочего блока зависит от его готовности в РСЯ.
Сервер ЮKassa для начисления рекламных минут не используется.

Документация: https://ads.yandex.com/helpcenter/ru/dev/android/rewarded

## Сборка

Актуальный SDK требует Android 7+ (minSdk 24), target/compile SDK 35, Java 17 и
AGP 8.9+. `buildozer.spec` подключает исходники Java, manifest-фрагмент,
репозитории и зависимость SDK. p4a hook `before_apk_assemble` после генерации
проекта устанавливает AGP 8.9.2, Gradle 8.11.1 и строку `ym_app_scheme`.
Старая ручная перепаковка APK поверх дистрибутива без Gradle-зависимости
не подходит: нужен нативный Android build с SDK и его manifest/resources.

Сборка стала требовать Android 7. Старый APK можно оставить для более старых
устройств, но в нём эта версия платёжного SDK не заработает.

## Проверка на телефоне

1. Указать ключ мобильного SDK тестового магазина и собрать APK с новой
   нативной зависимостью. Не устанавливать ключ API вместо sdk_key.
2. Открыть «Полная версия»: должен отображаться «ТЕСТОВЫЙ МАГАЗИН».
3. Ввести почту, нажать «Купить навсегда», пройти форму SDK тестовой картой
   из документации ЮKassa. Реальные карты в тестах не нужны.
4. Проверить, что подпись лицензии принята, показан подтверждённый доступ,
   повторное нажатие не создаёт вторую покупку. Сохранить личный код.
5. Проверить отказ/отмену, возврат через кабинет тестового магазина,
   отключение сети после отправки платежа и восстановление после перезапуска.
   Не очищать данные приложения ради проверки: это удалит и текущую партию.
   Восстановление можно проверить на другом устройстве/эмуляторе.
6. Подписка по 55 ₽ пока заблокирована флагом сервера
   subscriptions_available=false. Для отдельного теста её надо разрешить на
   сервере и настроить CRON; в live нужно отдельное согласование автоплатежей.

SDK RESULT_OK не выдаёт доступ. Сначала клиент проверяет заказ на нашем
сервере, затем проверяет RSA/SHA256-подпись лицензии. Запрос с неизвестным
результатом повторяет прежний request_id и токен. Отмена подтверждения не
считается доказательством отказа банка: приложение запрашивает фактический статус.

## Локальная проверка

Для тестов на компьютере требуется cryptography; Android использует
java.security.Signature и не включает Python cryptography.

```
python -m unittest discover -s tests -p "test_billing*.py"
```
