# 7.0.1

Исправлена нумерация Android для обновления существующего приложения в RuStore.
Ранние версии использовали автоматически вычисляемый python-for-android код:
`6.5.1` при minSdk 21 даёт `102160501`. Короткий явно заданный код `70000`
оказался меньше этой версии, несмотря на отображаемый номер `7.0.0`.

Новый номер: `7.0.1`, Version Code: `102170001`. Добавлена проверка согласованности
версий в меню, buildozer.spec и скрипте сборки, а также защита от возвращения
к короткой схеме. Для проверки с известным кодом последней версии магазина:

```powershell
py -3.12 tools/verify_release_version.py --previous-code 102160501
```

Скрипт сборки проверяет свежесть исходников и unsigned APK, а после подписи —
версию непосредственно в манифесте, подпись и выравнивание готового файла.
Включена обновлённая иконка приложения. Изменения интерфейса, обучения и ИИ
из версии 7.0.0 сохранены.
