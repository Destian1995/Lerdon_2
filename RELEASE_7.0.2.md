# 7.0.2

Наместник нежити заменён Морганой с портретом `files/army/death/morgana.png`.
Атака повышена с 8 до 208; защита 800, живучесть 50, класс 2, стоимость,
содержание и остальные параметры сохранены. Замена применяется к прежним
сохранениям, справочникам и герою, возрождающемуся в столице нежити.
Повторный запуск не прибавляет атаку ещё раз.

Значение налога выровнено по центру карточки при изменении её размера.
Портреты юнитов, героев, советников и значки фракций получили общие декоративные
рамки с цветом фракции. Рамки следуют фактическим границам изображения,
не изменяют размеры элементов и не перехватывают нажатия.

Android: `7.0.2`, Version Code `102170002`.
